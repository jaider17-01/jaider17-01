## 01 · Sobre mí

Soy desarrollador de software en formación y estudiante de **Ingeniería de Sistemas en las Unidades Tecnológicas de Santander (UTS)**, en Bucaramanga, Colombia.

Me interesa especialmente el **desarrollo backend con Java y Spring Boot**, el diseño de **APIs REST**, el trabajo con bases de datos y la creación de aplicaciones multiplataforma con **Flutter**. Mis proyectos académicos y personales son el espacio donde convierto requisitos en funcionalidades, practico decisiones de diseño y fortalezco mis fundamentos.

> Mi enfoque: entender el problema, organizar la solución y escribir código que otra persona pueda comprender y mantener.
