## 👨‍💻 Sobre mí

Soy desarrollador de software en formación y estudiante de **Ingeniería de Sistemas en las Unidades Tecnológicas de Santander (UTS)**, en Bucaramanga, Colombia. Me interesa convertir requisitos reales en soluciones claras, funcionales y fáciles de mantener.

Mi enfoque actual está en el **desarrollo backend con Java y Spring Boot**, el diseño de **APIs REST**, la persistencia de datos y el desarrollo móvil con **Flutter**. También trabajo con documentación de requisitos, arquitectura MVC y herramientas que ayudan a estructurar y ejecutar proyectos.

- 🔭 **En qué trabajo:** APIs, aplicaciones móviles y sistemas de gestión.
- 🌱 **En qué profundizo:** arquitectura backend, diseño de servicios y buenas prácticas.
- 🧩 **Cómo trabajo:** código legible, responsabilidades claras y documentación útil.
- 📍 **Ubicación:** Bucaramanga, Colombia.
- 📫 **Contacto:** [jaiderjjaimes@gmail.com](mailto:jaiderjjaimes@gmail.com)
