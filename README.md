## 01 / Perfil

Soy desarrollador de software en formación y estudiante de **Ingeniería de Sistemas en las Unidades Tecnológicas de Santander (UTS)**. Me enfoco en construir aplicaciones funcionales, comprender los requisitos y organizar el código para que sea claro y mantenible.

Mi principal interés está en el **backend con Java y Spring Boot**, las **APIs REST**, las bases de datos y el desarrollo multiplataforma con **Flutter**. He llevado estos intereses a proyectos académicos y personales que abarcan desde servicios backend hasta aplicaciones móviles y sistemas de gestión.
